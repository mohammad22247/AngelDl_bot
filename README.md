# 📥 AngelDl — Telegram Downloader Bot

ربات دانلودر تلگرام: کاربر لینک می‌فرستد، ربات فایل را برمی‌گرداند.
از اینستاگرام، تیک‌تاک، یوتیوب، ایکس و صدها سایت دیگر (با yt-dlp).

> **نکته امنیتی:** توکن ربات و `api_hash` هرگز در این ریپو نیستند.
> آن‌ها فقط در فایل‌های `.env` و `api.env` روی سرور زندگی می‌کنند
> (نگاه کنید به `.env.example`).

## ✨ امکانات

- **دانلود از صدها سایت** با yt-dlp (تا 720p) — اینستاگرام، تیک‌تاک، یوتیوب، ایکس، پینترست، ساندکلاد، اسپاتیفای و…
- **عضویت اجباری در کانال** (`FORCE_CHANNELS`): کاربر اول باید عضو کانال شود؛ دکمه «عضو شدم، بررسی کن» دارد.
- **پنج زبان** (فارسی، انگلیسی، روسی، چینی، عربی) با انتخاب زبان برای هر کاربر.
- **اشتراک پریمیوم**: خرید با Telegram Stars (خودکار)، TON و کارت‌به‌کارت (تأیید دستی ادمین). کاربران رایگان محدودیت روزانه و سقف حجم دارند؛ پریمیوم نامحدود است.
- **پنل مدیریت داخل ربات** (`/admin`): آمار، پیام همگانی، مدیریت پریمیوم، پرداخت‌های در انتظار، بن/آن‌بن، تنظیمات (قیمت، محدودیت، روزهای اشتراک، فروش روشن/خاموش).
- **صندوق پیام به مدیر** («📩 پیام به مدیر»): کاربر پیام می‌فرستد، ادمین با ریپلای جواب می‌دهد.
- **پست در کانال** (`/post`، فقط ادمین): انتشار پست متنی یا عکس‌دار در کانال با دکمه‌های شیشه‌ای (لینک‌دار)، با پیش‌نمایش و تأیید.
- **سقف ۲ گیگابایت** با سرور محلی Telegram Bot API (اختیاری؛ بدون آن سقف ۴۹ مگابایت تلگرام است).

## 🚀 راه‌اندازی سریع

```bash
git clone <repo-url> /root/dlbot && cd /root/dlbot
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cp .env.example .env
bash scripts/set-token.sh        # همان‌جا در ترمینال توکن، آیدی عددی ادمین و کانال عضویت اجباری را می‌پرسد
sudo cp systemd/dlbot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now dlbot
```

راهنمای کامل (سرور محلی Bot API، بازیابی دیتابیس، عیب‌یابی):
**[docs/DEPLOY.md](docs/DEPLOY.md)**

## ⚙️ تنظیمات (`.env`)

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | آیدی عددی تلگرام ادمین‌ها (با ویرگول جدا کنید) |
| `FORCE_CHANNELS` | کانال‌های عضویت اجباری، مثل `@ange1Vpn` |
| `FORCE_JOIN_URLS` | (اختیاری) لینک دعوت هر کانال، به همان ترتیب |
| `LOCAL_BOT_API` | (اختیاری) آدرس سرور محلی، مثل `http://127.0.0.1:8081` |
| `DB_PATH` | مسیر دیتابیس SQLite (پیش‌فرض `data.db`) |

**پیش‌نیاز مهم:** ربات باید **ادمین کانال** عضویت اجباری باشد،
وگرنه بررسی عضویت ناموفق می‌شود و هیچ‌کس از قفل رد نمی‌شود.

## 🗂 ساختار پروژه

```
AngelDl-bot/
├── bot.py                  # کد اصلی ربات
├── requirements.txt        # python-telegram-bot, yt-dlp, imageio-ffmpeg
├── .env.example            # نمونه تنظیمات (بدون مقدار واقعی)
├── scripts/
│   ├── run.sh              # اجرا/توقف/وضعیت بدون systemd
│   ├── set-token.sh        # وارد کردن توکن در .env (روی سرور)
│   └── set-api.sh          # وارد کردن api_id/api_hash در api.env (روی سرور)
├── systemd/
│   ├── dlbot.service               # سرویس ربات
│   └── telegram-bot-api.service    # سرویس سرور محلی Bot API
└── docs/
    └── DEPLOY.md           # راهنمای کامل استقرار
```

## 💾 پشتیبان‌گیری

برای انتقال به سرور جدید فقط دو فایل را همراه کد ببرید:

- `.env` و `api.env` (مقادیر محرمانه — با `scripts/set-token.sh` و `scripts/set-api.sh` دوباره ساخته می‌شوند)
- `data.db` (کاربران، پریمیوم و تنظیمات — بدون آن همه‌چیز از صفر شروع می‌شود)
